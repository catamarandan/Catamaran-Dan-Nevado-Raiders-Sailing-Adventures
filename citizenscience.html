Citizen Science Network Red de Ciencia Ciudadana

The Rim Run™ Citizen Science Network connects trained local observers with a standardized field system to monitor reef conditions across multiple countries. La Red de Ciencia Ciudadana Rim Run™ conecta observadores locales capacitados con un sistema estandarizado de campo para monitorear las condiciones de los arrecifes en múltiples países.

The Rim Run™ expedition serves as the coordinating field platform, establishing standards, conducting primary observations, and developing trained observers within each country. La expedición Rim Run™ actúa como la plataforma de campo coordinadora, estableciendo estándares, realizando observaciones primarias y desarrollando observadores capacitados en cada país.

How the Network Works Cómo funciona la red

This network is built to establish trained, locally anchored observers in every participating country. Esta red está diseñada para establecer observadores capacitados y arraigados localmente en cada país participante.
