Section 02 · Chemical Oceanography · L17 / 32

Modeling

Model types, hierarchy, validation, and integration into CMIE

Lecture
EN — English

Modeling in chemical oceanography spans four distinct types — thermodynamic calculators, physical reanalysis products, regional process models, and Earth System Models — each with different roles, skill ranges, and confidence implications inside GROAN. Using the wrong model type for a given question is not a minor error; it produces Decision Score outputs that cannot be defended at the PhD or operational level.

1 · Thermodynamic calculators: CO2SYS and SeaCarb. CO2SYS is not a model in the parameterization sense. It solves the carbonate equilibrium system from measured inputs using established thermodynamic constants. Its output uncertainty derives entirely from input measurement error, not from model structural error. Treating CO2SYS output as generically "modeled" is a classification error CMIE must not make. CO2SYS is mandatory post-processing for every MOOP station record. SeaCarb serves as the cross-check; outputs must agree within ±0.02 Ω or the record is flagged for re-processing.

2 · Physical reanalysis: GLORYS 1/12°. GLORYS provides the circulation backbone — SST, salinity, currents — at ~8 km resolution. It is the minimum viable spatial product for GROAN macro-scale attribution (introduced in L16). Model skill must be validated against at least one moored station per reef zone before CMIE ingestion. Validated GLORYS (r² > 0.85, RMSE < ±0.1 Ω equivalent) = High eligible. Unvalidated = Moderate automatic.

3 · Regional process models: ROMS. When bay-scale or sub-zone resolution is required — SGD plume dynamics, river discharge fronts, circulation within a lagoon — ROMS regional configurations resolve features that GLORYS cannot. ROMS requires both a moored station anchor and a cross-zone transect for validation. Red Sea specificity: the operational ROMS-Red Sea configuration resolves the inverse seasonal forcing (peak thermal stress in summer, not wet season) that global GLORYS misrepresents. For the Red Sea proof-of-concept case study, ROMS-Red Sea is mandatory; GLORYS alone is inadmissible.

4 · Earth System Models: CMIP6 SSP5-8.5. CMIP6 provides 2045–2055 Ω alarm projections at 1° grid resolution — approximately 100 km, far coarser than reef meso-scale. GROAN does not consume the ensemble mean alone; it reports the full ensemble spread (±0.3 Ω at 2050 for Caribbean under SSP5-8.5) to CMIE so that uncertainty is propagated into the Decision Score. A point projection without ensemble range is classified as Low confidence.

Key argument: GROAN's model hierarchy is not a menu — it is a pipeline. CO2SYS runs first on every record. GLORYS provides the spatial field. ROMS fills bay-scale gaps. CMIP6 supplies the projection horizon. Each layer feeds the next. Skipping CO2SYS to use GLORYS SST as a carbonate proxy is a protocol violation that corrupts the entire CMIE input chain.

ES — Español

El modelado en oceanografía química abarca cuatro tipos distintos — calculadoras termodinámicas, productos de reanálisis físico, modelos de procesos regionales y Modelos del Sistema Terrestre — cada uno con diferentes roles, rangos de habilidad e implicaciones de confianza dentro de GROAN. Usar el tipo de modelo incorrecto para una pregunta dada no es un error menor; produce salidas del Puntaje de Decisión que no se pueden defender a nivel de doctorado u operacional.

1 · Calculadoras termodinámicas: CO2SYS y SeaCarb. CO2SYS no es un modelo en el sentido de parametrización. Resuelve el sistema de equilibrio del carbonato a partir de entradas medidas usando constantes termodinámicas establecidas. La incertidumbre de su salida deriva enteramente del error de medición de entrada. Tratar la salida de CO2SYS como genéricamente "modelada" es un error de clasificación que CMIE no debe cometer. CO2SYS es post-procesamiento obligatorio para cada registro de estación MOOP. SeaCarb sirve como verificación cruzada; las salidas deben coincidir dentro de ±0.02 Ω o el registro se marca para reprocesamiento.

2 · Reanálisis físico: GLORYS 1/12°. GLORYS proporciona la columna vertebral de circulación — TSM, salinidad, corrientes — a resolución de ~8 km. La habilidad del modelo debe validarse contra al menos una estación amarrada por zona de arrecife antes de la ingestión por CMIE. GLORYS validado (r² > 0.85, RMSE < ±0.1 Ω equivalente) = Alto elegible. No validado = Moderado automático.

3 · Modelos de procesos regionales: ROMS. Cuando se requiere resolución a escala de bahía — dinámica del penacho SGD, frentes de descarga fluvial, circulación dentro de una laguna — las configuraciones regionales ROMS resuelven características que GLORYS no puede. Especificidad del Mar Rojo: la configuración ROMS-Mar Rojo operacional de resuelve el forzamiento estacional inverso que GLORYS global representa incorrectamente. Para el estudio de caso del Mar Rojo, ROMS-Mar Rojo es obligatorio; GLORYS solo es inadmisible.

4 · Modelos del Sistema Terrestre: CMIP6 SSP5-8.5. CMIP6 proporciona proyecciones de alarma de Ω para 2045–2055 a resolución de cuadrícula de 1° — aproximadamente 100 km. GROAN no consume solo la media del conjunto; reporta el rango completo del conjunto (±0.3 Ω en 2050 para el Caribe bajo SSP5-8.5) a CMIE para que la incertidumbre se propague al Puntaje de Decisión.

Argumento clave: La jerarquía de modelos de GROAN no es un menú — es una canalización. CO2SYS se ejecuta primero en cada registro. GLORYS proporciona el campo espacial. ROMS llena los vacíos a escala de bahía. CMIP6 suministra el horizonte de proyección. Omitir CO2SYS para usar la TSM de GLORYS como proxy de carbonato es una violación de protocolo que corrompe toda la cadena de entrada CMIE.

Application
EN — English
  • 01Run CO2SYS on every MOOP station record before any spatial or temporal analysis — it is not optional post-processing. A record without CO2SYS output has no carbonate chemistry and cannot enter the CMIE pipeline.
  • 02Cross-check every CO2SYS Ω output with SeaCarb. If the two calculators disagree by more than ±0.02 Ω, flag the record, audit the input parameters, and do not advance to kriging until resolved.
  • 03When using GLORYS for a reef zone, document the r² and RMSE of the GLORYS-vs-moored comparison explicitly in the station metadata — not as a footnote, as a required field. Unvalidated GLORYS fields are Moderate regardless of spatial resolution.
  • 04For the Red Sea proof-of-concept case study, substitute ROMS-Red Sea () for GLORYS as the circulation backbone. GLORYS misrepresents Red Sea summer peak stress — using it alone invalidates the seasonal attribution argument.
  • 05When reporting CMIP6 alarm thresholds to any institutional contact (, CORDAP, embassy letters), always state the ensemble range alongside the mean. "Ω drops to 2.5 ± 0.3 by 2050 under SSP5-8.5" is defensible. "Ω drops to 2.5 by 2050" is not.
